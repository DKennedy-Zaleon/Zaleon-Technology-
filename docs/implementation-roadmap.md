# Implementation Roadmap

## Milestone 1 — Demoable UI
- Portal shell
- Dashboard
- My Tickets
- Ticket detail
- New request
- Profile / settings
- Static demo data

## Milestone 2 — Real API
- PostgreSQL
- Organizations
- Users
- Conversations
- Tickets
- Messages
- Notifications
- Resolution records

## Milestone 3 — Jira
- Jira Service Management OAuth/API integration
- Ticket create/update/comment/resolve synchronization
- Mapping between Zaleon and Jira states

## Milestone 4 — Identity
- Microsoft Entra ID SSO
- Directory profile enrichment
- Department / role / group-based routing
- Priority user policies

## Milestone 5 — Live queue
- Human-first waiting state
- Convert-to-queued-ticket
- Technician claim
- User rejoin notification
- Continuous thread

## Milestone 6 — Knowledge Engine
- Mandatory closeout form
- Resolution ingestion
- Similar-ticket clustering
- Draft article generation
- Internal vs user-facing classification
- Human approval
- Contextual article suggestions

## Milestone 7 — Production hardening
- RBAC
- Audit log
- rate limiting
- encryption
- retention policies
- tenant isolation
- observability
- backups
- security review
