UPLOAD
Upload the CONTENTS of this folder to the root of your GitHub repository, replacing the existing website files. Cloudflare should redeploy automatically from GitHub.

BUTTONS
- All "Get in Touch" buttons link to contact.html.
- "Our Services" links to services.html.
- Service "Talk to us" links go to contact.html.
- Email and phone links are clickable.

CONTACT FORM
The form currently uses a mailto fallback: pressing Send Message opens the visitor's default email client and pre-fills a message to support@zaleon.tech.
This works without any third-party service, but it is not a true server-side form submission.
